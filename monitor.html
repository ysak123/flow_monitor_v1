How to use Flow monitor

    
Flow monitor shows your APR and LEC runs on the Linux host from your Windows desktop, and takes you straight to the error lines when something breaks.
      It only reads files over SSH: nothing is installed on the host, nothing there is changed, and no website is hosted anywhere.


    
1Before you start (once)

    
    
      
  • Windows 10 or 11 (it has the SSH client built in), Python 3 from python.org, and Google Chrome.
        start_monitor.bat tells you if Python is missing.
    • 
      
  • An SSH key. The monitor finds yours in C:\Users\<you>\.ssh by itself. No key yet? Press Create a key in Settings.
    • 
      
  • The key must be known to the Linux host. Press Install key on host in Settings: a PowerShell window opens where you type your
        Linux password once. Your password never goes through this page.
    • 
    


    
2Start the monitor

    
Double-click start_monitor.bat. It first checks that Python and the Windows SSH client are installed and tells you what to do if not.
      Then a minimised window called Flow monitor bridge appears (the helper), and this page opens in its own window at
      http://127.0.0.1:8899. Closing either window stops both. 127.0.0.1 means your own PC: the helper runs on your desktop and fetches data over SSH, because a browser can't open SSH connections itself.


    
3Connect to the Linux host

    
The page opens on Connect to your Linux host. Fill in the host and your Linux user name; your key is found automatically.
      Press Connect; the monitoring page appears once SSH works. Next time it connects by itself.
      To change host later, use Settings (the gear, or the connection pill at the top).

    
    
Everything you set up, connection, categories and labels, is saved in monitor_config.json next to start_monitor.bat.
      Copy that file to back it up or to move to another PC. It is personal, so it is never uploaded to git.


    
4Add a category and paste your blocks

    
Pick the APR or LEC tab, then press New category. Give it a name such as APEX version 1.1.2 and paste one path per line.
      Add a label after a | to remember what the run is for: /nfs/.../r2g/blk_b/apr_snps/logs | retry with new floorplan.

    
APR accepts a block root, its apr_snps folder or apr_snps/logs. LEC accepts a block root or lec/<block>/logs.
      Plain log folders work in either tab. Paste a path into the wrong tab and the page tells you which tab it belongs in.

    

    
5Read the overview

    
Each block is one line: name, your label, status, progress and the current stage. Anything that needs you is collected in Needs attention at the top,
      and the tab shows how many.

    
    

      
Running
A stage log changed recently and the stage has no pass or fail file yet.

      
Failed
A stage wrote a .fail file.

      
Stopped
The current stage's log stopped changing with no pass or fail file: the job was probably killed or ran out of resources.

      
Complete
The last stage passed.

      
Idle
Nothing is running and nothing failed; the next stage hasn't started.

      
Silent
A watched log folder has had no writes for longer than its alert time.

      
Path problem
The path doesn't exist on the host, or belongs in the other tab.

    


    
6Look inside a block

    
Click a line to open it. The stages are drawn as a wire: green passed, orange running, red failed, hollow not started.
      Under each stage you see how long it took, or how long it has been running. Press a stage to open its log. Copy run directory puts the path on your clipboard for your terminal.

    

    
7Debug a failure

    
Press Show errors in Needs attention, or press the failed stage. The log opens on Errors: every error in the whole file, with repeats grouped and counted,
      in the order they first happened, so the root cause is usually at the top. Click a message to see the lines around it.
      Previous and Next (or the p and n keys) step through each occurrence. Warnings works the same way.

    

    
8Follow a running stage

    
Live tail shows the end of the log and adds new lines as they are written. Type in Filter to keep only matching lines. Press Esc or the cross to close the panel.

    

    
9LEC runs

    
The LEC tab has its own categories. Each run shows its Conformal phase, progress within the phase, key points, run time and memory,
      and the result from lec_summary.rpt when it finishes.

    

    
10Alerts, themes and settings

    
When a block fails, stops, finishes, or a log folder goes silent, the page shows a banner, a Windows notification and plays an alarm sound. Turn these on or off in Settings.
      The sun and moon button switches light and dark; Settings → Appearance also offers Follow Windows and your own accent colour.

    

    
If something goes wrong

    

      
"Not connected"
Check VPN, then open Settings and press Connect. "Permission denied": check the user name, then press Install key on host.

      
Remote Python
If the host says python3 isn't found, set Remote Python command in Settings, for example /usr/bin/python3.

      
Stuck on Checking
Run start_monitor.bat again; it replaces an old helper with the current one.

      
"Flow monitor has stopped"
The helper window was closed. Start start_monitor.bat again.
